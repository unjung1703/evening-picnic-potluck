# 우리들의 저녁 피크닉

함께 준비하는 저녁식사 포트락의 조회 전용 정적 웹앱입니다.

공유 URL: https://unjung1703.github.io/evening-picnic-potluck/

이 저장소에는 참가자용 공개 파일만 들어 있습니다. 별도 로그인, 백엔드, 데이터베이스가 없습니다. 관리자 편집기는 로컬 소스 패키지에 별도로 보관합니다.

## 데이터 갱신

검증한 `data/items.json`을 `main`에 커밋하면 GitHub Pages가 같은 URL에 재배포합니다. GitHub Actions에서 배포 성공을 확인하고 공유 화면의 새로고침으로 업데이트 버전을 확인하세요.

설정: Settings → Pages → Deploy from a branch → main → /(root).

가격은 전체 수량의 예상 비용입니다. 실제 결제 완료 금액이 아닙니다. 상품명·중량·담당자·비용 구분이 불확실한 값은 임의로 확정하지 않습니다.
